# Personal site

The goal is to have a personal website that is very simple and easy to maintain.

## Key features

These are the most important things about the project

### Scalable
Simple to update and add new things to.

### Modular
Simple to add new pages or projects to it. Not having to conform to a specific framework. Example: If I had a react project the draws a cat and wanted to add that as a subpage in lab it should be easy enough.
